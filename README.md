# Cédrai / Field Notes

디지털 포렌식과 웹 보안을 공부하며 남기는 개인 기술 블로그입니다.

문제를 풀면서 알게 된 것, 수업이나 개인 공부 중에 정리한 내용, 직접 만들어본 것들을 모읍니다. 답을 구하는 데서 끝내지 않고 어떤 과정을 거쳐 이해했는지 함께 적어두려고 합니다. 나중에 비슷한 문제를 만났을 때 다시 꺼내볼 수 있는 노트가 되었으면 합니다.

[블로그 둘러보기](https://cedrai05.github.io/) · [포트폴리오](https://www.cedrai.info/) · [GitHub](https://github.com/Cedrai05) · [티스토리](https://rinhye05.tistory.com/)

## 어떤 기록을 남기나요?

주로 Dreamhack이나 CTF 문제를 푼 과정, 보안 개념과 도구를 공부한 내용을 기록합니다. 포렌식과 웹 보안에 관심이 많고, Linux나 전공 수업에서 배운 내용도 함께 정리하고 있습니다.

글을 모아둘 큰 분류는 여섯 가지입니다.

- **개발** — 직접 만든 프로젝트와 개발 과정
- **CTF/Wargame** — Dreamhack, 워게임, CTF 문제 풀이
- **Bug Bounty** — 버그바운티 활동과 관련 기록
- **블로그/기술문서** — 개인 공부, 보안 개념, 도구 사용법, 전공 정리
- **논문/컨퍼런스** — 읽은 논문과 학회·컨퍼런스에서 배운 내용
- **공모전/자격증** — 준비 과정과 참여 기록

아직 글이 없는 분류도 있습니다. 공부하고 경험하는 범위가 넓어지는 만큼 이곳의 기록도 조금씩 채워갈 생각입니다.

## 글 찾아보기

큰 분야는 카테고리로 고르고, 그 안에서는 티스토리의 원래 카테고리로 범위를 더 좁힐 수 있습니다. `DreamHack / forensic`, `Secure / Linux`, `Major / 자료구조`처럼 상위·하위 이름을 함께 표시합니다. 글 제목으로 분야를 추측하지 않고, 티스토리에서 실제로 어느 카테고리에 넣어둔 글인지에 따라 나눕니다.

검색어도 필터와 함께 사용할 수 있습니다. 글을 읽고 목록으로 돌아오면 선택했던 카테고리와 주제, 검색어, 스크롤 위치가 복원됩니다. 여러 글을 찾아 읽을 때 매번 처음부터 목록을 내려가지 않아도 됩니다.

화면은 다크·라이트 테마를 지원하고, 휴대폰에서도 볼 수 있도록 구성했습니다. 상단 메뉴에서는 GitHub와 포트폴리오, 프로젝트 페이지로 이동할 수 있습니다.

## 티스토리와 함께 운영합니다

글은 기존에 사용하던 티스토리에 작성합니다. 이 블로그에서는 티스토리의 글 목록과 공개글 본문을 불러와 보여주기 때문에, 새 글을 올릴 때마다 저장소를 수정할 필요는 없습니다. 티스토리에서 글의 카테고리를 옮기면 다음 목록 갱신에 반영됩니다.

공개글은 이곳에서 바로 읽을 수 있고, 보호글은 티스토리 원문으로 이동해 확인합니다. 보호글의 본문이나 비밀번호는 이 저장소에 보관하지 않습니다.

글을 불러오는 API는 포트폴리오의 Vercel 서버에서 운영합니다. 티스토리 화면 구조가 바뀌거나 API에 문제가 생기면 연동 코드를 확인해야 합니다.

## 사이트 구성

HTML, CSS, JavaScript로 만들었고 GitHub Pages에서 운영합니다. 별도의 패키지 설치나 빌드 과정은 없습니다. 포트폴리오와 오가며 볼 수 있도록 화면의 색상과 분위기도 맞췄습니다.

화면 구성은 `index.html`, 스타일은 `styles.css`, 글 목록과 검색·필터 동작은 `app.js`에서 관리합니다. 카테고리 목록은 `posts.js`에 있고, 티스토리 연동 API 코드는 `integrations/portfolio-api/`에서 확인할 수 있습니다. 실제 API는 포트폴리오 저장소의 `app/api/blog-feed/route.ts`와 `app/api/blog-post/route.ts`에서 운영합니다.

포트폴리오에는 프로젝트와 활동을 정리하고, 이곳에는 그 사이에서 배우고 고민한 과정을 남깁니다.
